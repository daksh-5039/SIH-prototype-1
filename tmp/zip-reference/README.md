# BhopalGo v18

Expanded Explore database with additional official Bhopal-area attractions, including Manua Bhan Ki Tekri, Birla Mandir, Bharat Bhavan, Lower Lake, Jama Masjid, Shaukat Mahal, Rani Kamlapati Palace, Shaurya Smarak, Fish Aquarium, Kamla Park, Islamnagar and Samasgarh. Added Tekri chat/geocoding aliases and verified Tripadvisor review data for Manua Bhan Ki Tekri.

Data scope: attraction metadata is curated from official Bhopal District tourism and Incredible India sources; live weather/routing remain API-driven. Crowd reports remain community/prototype signals.
